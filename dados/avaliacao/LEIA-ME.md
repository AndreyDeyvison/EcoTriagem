# Dados da avaliação de ponta a ponta

`perguntas_teste.csv` — perguntas usadas **só** para avaliar o sistema completo
(`python -m src.integracao.avaliar_sistema`), com a intenção correta de cada uma.

**Não usar estas frases no treino do PLN.** Se elas entrarem no treino, a
avaliação mede memorização e não generalização, e o resultado deixa de valer.

As imagens da avaliação são as do conjunto de **teste** em
`dados/processados/divisao_trashnet.csv`.
